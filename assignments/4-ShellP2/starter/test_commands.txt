# Test Commands for DSH Shell

## Build and Test Commands

### If you have gcc (Linux/Mac/WSL):
```bash
cd starter
make
./dsh
```

### If you have clang (Linux/Mac):
```bash
cd starter
clang -Wall -Wextra -g -o dsh *.c
./dsh
```

### Manual compilation (if make doesn't work):
```bash
cd starter
gcc -Wall -Wextra -g -o dsh dsh_cli.c dshlib.c dragon.c
```

## Test Commands to Run in DSH

Once the shell is running, test these commands:

### Basic Commands:
```
ls
pwd
echo "hello world"
uname -a
```

### Built-in Commands:
```
exit
cd /tmp
cd
dragon
rc
```

### Quoted String Tests:
```
echo "hello     world"
echo "  spaced string  "
```

### Error Handling Tests:
```
nonexistent_command
./nonexistent
```

### Expected Behavior:
- `cd <directory>` should change directories
- `cd` with no args should do nothing
- `rc` should show last return code
- `dragon` should print ASCII art
- Quoted strings should preserve spaces
- Non-existent commands should show "Command not found in PATH"

## Run Tests with BATS (if available):
```bash
cd starter
make test
```
